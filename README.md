# Personal TV playlist — Turkey and Sweden

Paste this URL into your IPTV player's playlist field:

**https://raw.githubusercontent.com/onealper/IPTV/master/custom.m3u8**

The playlist combines Turkey and Sweden from [Free-TV/IPTV](https://github.com/Free-TV/IPTV) with additional channels from [zek's Turkish playlist](https://gist.github.com/zek/209bcd5888473014d4cc5d82390e7d56). Existing Free-TV streams take priority when a channel appears in both lists. Duplicate channel names and URLs are removed within each country. Source files for other countries remain in the fork, but are excluded from **custom.m3u8**.

## Change countries

Open [custom-settings.json](custom-settings.json), click the pencil button, and edit `countries`. For example:

```json
"countries": ["turkey", "sweden"]
```

Remove `"sweden"` to keep only Turkey. Country names match filenames in the original project's `lists` folder, without `.md` (for example `uk`, `usa`, `germany`). Imported playlists for a removed country are also excluded.

## Add a channel

Add an entry to `extra_channels` in [custom-settings.json](custom-settings.json):

```json
"extra_channels": [
  {
    "country": "turkey",
    "name": "Your channel name",
    "url": "https://example.com/live/playlist.m3u8",
    "logo": "https://example.com/logo.png",
    "epg_id": "YourChannel.tr"
  }
]
```

Replace the example values with the real channel details. `logo` and `epg_id` are optional. The country must be selected in `countries`. An extra channel replaces an existing channel with the same normalized name in that country, so this also lets you change a stream URL. Keep commas between entries and do not add a trailing comma.

## Remove a channel

Put its name in `exclude_channels`:

```json
"exclude_channels": ["Channel to remove", "Another channel"]
```

Names are matched without differences in capitalization, spacing, accents, resolution labels, or geo-blocking labels. Exclusions apply to all sources, including your additions.

## Updates

The **Update personal playlist** GitHub Action fetches the latest source playlists once a day and whenever settings or the builder change. You can also open **Actions → Update personal playlist → Run workflow** for an immediate refresh. GitHub schedules can be delayed; GitHub can disable scheduled workflows in public repositories after 60 days without repository activity.

Only `custom.m3u8` is generated by this workflow. Your settings and personal additions remain unchanged. If a source cannot be downloaded or is malformed, the update fails and preserves the last published playlist.

Channel availability depends on the stream provider, your location, and your player's support for the stream format. Some entries are geo-blocked, require a subscription, or are not live all day. Importing an entry does not verify playback or change the provider's access requirements.
